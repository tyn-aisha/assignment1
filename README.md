# Kazakh Horse Culture Project

## Overview
This project is an educational website dedicated to Kazakh Horse Culture. It aims to provide visitors with insights into the rich traditions and significance of horses in Kazakh culture.

## Project Structure
The project consists of the following files and directories:

```
assignment1/
├── index.html       # Main page with an overview of Kazakh Horse Culture
├── about.html       # Information page detailing historical and cultural facts
├── contact.html     # Contact page with a table and a form for inquiries
├── css/
│   └── style.css    # External CSS file for styling all pages
├── images/          # Directory for storing images used in the project
├── media/           # Directory for storing multimedia files related to the project
└── README.md        # Documentation for the project
```

## Page Descriptions

### index.html
- Serves as the main landing page.
- Contains semantic HTML5 elements: header, nav, main, and footer.
- Features:
  - One `<h1>` element for the main title.
  - Two `<h2>` sections for subheadings.
  - An unordered list and an ordered list to present information.
  - Two images with meaningful alt text to enhance understanding.

### about.html
- Provides detailed information about Kazakh Horse Culture.
- Features:
  - A 3–5 sentence paragraph summarizing the culture.
  - An ordered list with 4–6 significant historical dates.
  - An unordered list with at least 4 interesting facts.
  - A figure with a figcaption to illustrate a key aspect of the culture.
  - A blockquote with a source for credibility.
  - Use of `<strong>` or `<em>` for emphasis.
  - A multimedia placeholder for future content.
  - An external link that opens in a new tab.

### contact.html
- Contains a contact form and a data table.
- Features:
  - A table with a caption, thead, tbody, and tfoot sections.
  - At least 4 columns and 5 data rows, with appropriate `<th>` elements.
  - A form with:
    - A fieldset and legend for organization.
    - Labels connected to input fields for accessibility.
    - At least five different input types, all with required attributes.
    - Native validation for user inputs.
    - Radio buttons grouped by name.
    - A textarea for additional comments.
    - A submit button for form submission.

## CSS Styling
The `css/style.css` file styles all HTML pages using:
- Element, class, and ID selectors.
- Margin, padding, and border properties for layout.
- A color palette using 3–4 colors in different formats.
- Various units including px, %, rem, and vh for responsive design.
- Styles for navigation, tables, and forms, including hover and focus states.

## Usage
To view the project, open the `index.html` file in a web browser. Navigate through the pages using the navigation bar present on all pages. Each page is designed to be user-friendly and informative, adhering to semantic HTML5 standards.

## Conclusion
This project serves as a comprehensive introduction to Kazakh Horse Culture, utilizing modern web development practices to create an engaging and educational experience.
